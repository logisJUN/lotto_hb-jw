# 로또랩 (LottoLab)

역대 로또 당첨번호를 조회하고, 번호를 뽑아 저장하고, 당첨 여부를 확인하는 모바일 웹앱입니다. 빌드 과정 없이 정적 파일만으로 동작하며, 모든 수치는 매주 자동으로 갱신되는 실제 당첨 데이터(`data/lotto.json`)로 계산합니다.

기능이 생기거나 바뀔 때마다 무엇이 생겼고 어떻게 쓰는지는 **[변경 기록(CHANGELOG.md)](CHANGELOG.md)**에 적습니다.

| 하단 탭 | 파일 | 하는 일 |
| --- | --- | --- |
| 홈 | `index.html` | 최신 당첨번호와 1등 당첨금·다음 추첨 카운트다운, **기능 지도**(모든 기능 12개 바로가기), 내 번호 결과 요약, 빠른 번호 뽑기(5게임) |

## 내 번호와 가장 많이 맞은 회차 (통계 화면)

1. 통계 화면 위쪽의 **번호 골라서 조회하기**를 누르면 아래에서 번호 고르기 창이 올라옵니다.
2. 1~45 중 번호를 정확히 6개 고릅니다. 고른 번호를 다시 누르면 빠지고, 6개를 넘게 고를 수는 없습니다. 6개가 되기 전까지 **조회하기** 버튼은 눌리지 않습니다. **무작위로 채우기**, **초기화**도 있습니다.
3. **조회하기**를 누르면 창이 닫히고, 화면에 결과 카드가 나타납니다. 계산은 `js/app.js`의 `findBestMatches`가 합니다.
   - 고른 6개를 1회부터 최신 회차까지 모든 당첨번호 6개와 비교해 맞은 개수를 셉니다. 보너스 번호는 개수에 넣지 않습니다.
   - 3개 이상 맞은 회차만 남깁니다(3개 미만은 5등에도 못 듦).
   - 맞은 개수가 많은 순, 같으면 보너스 번호까지 맞은 회차, 그래도 같으면 최근 회차 순으로 줄을 세워 앞의 5개를 고릅니다.
   - 고른 5개를 회차 번호 내림차순(최신 회차가 위)으로 보여 줍니다. 3개 이상 맞은 회차가 5개보다 적으면 있는 만큼만 보여 줍니다.
4. 결과 카드에는 내가 고른 번호, 3개 이상 맞은 회차의 전체 개수(3·4·5·6개별), 회차마다 날짜·맞은 개수·등수·당첨번호(맞은 번호 강조)·맞은 번호 목록이 나옵니다.
5. **번호 바꿔서 다시 조회**는 고른 번호를 유지한 채 창을 다시 엽니다. **이 번호 저장**은 보관함에 넣습니다.
6. 기간 선택(전체/100회 등)과 상관없이 항상 전체 회차에서 찾습니다. 같은 설명이 창 안의 **어떻게 찾나요?**에도 있습니다.

## 디자인

- 화면 테마는 기기 설정(라이트/다크)을 따르고, 머리말 오른쪽 버튼으로 기기 설정 → 라이트 → 다크 순서로 바꿀 수 있습니다.
- 색은 역할별로만 씁니다: 남색(브랜드·주요 버튼·선택), 주황(당첨금), 초록(당첨·일치), 빨강(삭제·제외). 로또 공 색(노랑/파랑/빨강/회색/초록)은 공에만 씁니다.
- 색과 간격 값은 `css/style.css` 맨 위의 토큰(`--primary` 등)에 모여 있습니다.
- 저장한 번호는 이 기기의 브라우저(localStorage)에만 보관됩니다. 보관함의 **백업·옮기기**로 파일이나 링크로 옮길 수 있습니다.

## GitHub Pages로 임시 사이트 열기

1. GitHub에서 새 저장소(Repository)를 만듭니다. (예: `lottolab`)
2. 이 폴더 안의 파일 전체를 저장소에 업로드합니다. (`Add file` → `Upload files`)
3. 저장소의 `Settings` → `Pages`에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 두고 `Save`를 누릅니다.
4. 1~2분 뒤 `https://<GitHub 아이디>.github.io/<저장소 이름>/` 주소로 열립니다.

## 역대 당첨번호 자동 수집

`data/lotto.json`에 1회부터 최신 회차까지의 당첨번호가 저장되고, 매주 자동으로 갱신됩니다.

- GitHub Actions(`.github/workflows/update-lotto.yml`)가 토요일 21:07·21:47·22:37, 일요일 00:07·09:07·15:07(한국 시간)에 `scripts/fetch-lotto.mjs`를 실행하고(이미 받았으면 바로 끝남), 이어서 `scripts/analyze.mjs`로 [억지 분석 기록](analysis/README.md)을 갱신합니다.
- 스크립트는 동행복권에서 파일에 없는 회차만 받아 추가하고, 변경이 있으면 저장소에 커밋합니다.
- 바로 갱신하고 싶으면 저장소의 `Actions` → `로또 당첨번호 갱신` → `Run workflow`를 누릅니다.
- 사이트에서는 `fetch('data/lotto.json')`으로 읽습니다. 형식은 회차당 한 줄이고, `prizes`와 `winners`는 1~5등 1인당 당첨금과 당첨자 수입니다.

```json
{"round":1100,"date":"2023-12-30","numbers":[17,26,29,30,31,43],"bonus":12,"prizes":[2207575472,59050373,1667160,50000,5000],"winners":[13,81,2869,146262,2503154],"totalSales":116187023000}
```

예약 실행은 기본 브랜치(`main`)에 있는 워크플로만 동작합니다.
